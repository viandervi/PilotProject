# Sprint 1 / PR 1 — Database foundation

This is an additive database foundation for the existing single-user POC. No production multi-user auth or ingestion is implemented by this PR.

## Local prerequisites

Create a PostgreSQL database and user, then set `JDBC_PASSWORD` (and optionally `JDBC_URL`, `JDBC_USER`). Run with `MICRONAUT_ENVIRONMENTS=database` to activate the datasource and Flyway migrations. Existing POC mode remains unchanged without that environment.

## Ownership model

A creator is identified by a stable verified Google subject, not by email. A channel has one creator owner in V1; team/shared channel permissions are out of scope. Video IDs are globally unique. UUIDs are generated by the application.
